# Glossary

- Helper: One independent BotSystem Python program.
- Bot ID: Numeric identifier of a 3Commas bot; treat as private operational data.
- Pair: Market symbol selected for a trading bot.
- Paper account: Simulated account used for testing without real funds.
- API key: Public identifier paired with a private API secret.
- Apprise URL: Notification endpoint that may contain credentials.
- Interval: Delay between helper cycles.
- Trailing stop: Stop level that follows favorable price movement.
- Take profit: Rule that closes a position after a configured gain.
